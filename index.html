หน้าแสดงผลงานนี้สรุปโครงสร้างการใช้งานของระบบผ่านมุมมองนักศึกษา ช่าง และผู้ดูแลระบบ โดยเน้นหน้าตาและลำดับการทำงานหลัก ไม่เชื่อมต่อระบบจริงและไม่มีข้อมูลจริง

Project Overview

ระบบเดียว ครอบคลุมวงจรงานซ่อมตั้งแต่แจ้งปัญหาจนปิดงาน

ออกแบบให้ผู้ใช้แต่ละบทบาทเห็นเฉพาะสิ่งที่เกี่ยวข้องกับงานของตนเอง และติดตามความคืบหน้าได้จากสถานะเดียวกัน

3 บทบาทหลัก

นักศึกษา ช่าง และผู้ดูแลระบบ

1 Repair Lifecycle

ใช้สถานะร่วมกันตั้งแต่แจ้งงานจนเสร็จสิ้น

Web Responsive Interface

รองรับการใช้งานทั้งคอมพิวเตอร์และอุปกรณ์พกพา

Role-based Experience

แยกหน้าที่ชัดเจนตามบทบาทผู้ใช้งาน

แต่ละบทบาทมีจุดเริ่มต้นและเครื่องมือที่ต่างกัน แต่เชื่อมกันด้วยรายการแจ้งซ่อมเดียวกัน

01

นักศึกษา

แจ้งปัญหาและติดตามงานได้ด้วยตัวเอง

เน้นการแจ้งข้อมูลให้ครบ ดูสถานะล่าสุด จัดการนัดหมาย และย้อนดูประวัติรายการเดิม

  • หน้าแจ้งซ่อมห้องพัก
  • ติดตามสถานะและรายละเอียดงาน
  • ยืนยันหรือขอเลื่อนนัดหมาย
  • ดูประวัติการแจ้งซ่อม
02

ช่าง

จัดลำดับงาน ประสานเวลา และบันทึกผลการซ่อม

รวมรายการงานที่รับผิดชอบ ปฏิทินงาน รายละเอียดการซ่อม วัสดุที่ใช้ และประวัติงานที่เสร็จแล้ว

  • รายการงานของฉัน
  • ปฏิทินและการนัดหมาย
  • อัปเดตความคืบหน้าและผลซ่อม
  • วัสดุและประวัติงานที่เสร็จแล้ว
03

ผู้ดูแลระบบ

มองภาพรวมและดูแลข้อมูลที่ระบบใช้ร่วมกัน

จัดการใบแจ้งซ่อม ผู้ใช้ ห้องและสถานที่ วัสดุ รายงาน และข้อมูลงานระบบที่เกี่ยวข้องกับการบริหารหอพัก

  • Dashboard และจัดการงานซ่อม
  • ผู้ใช้ ห้อง และสถานที่
  • วัสดุและข้อมูลหลัก
  • รายงานและงานดูแลระบบ

Repair Workflow

ลำดับงานหลักที่เชื่อมทั้งสามบทบาท

แสดงภาพรวมการส่งต่องาน โดยไม่เปิดรายละเอียดภายในของระบบจริง

  1. 01

    นักศึกษาแจ้งปัญหา

    ระบุประเภท สถานที่ รายละเอียด และข้อมูลประกอบที่จำเป็น

  2. 02

    ตรวจสอบและรับงาน

    รายการเข้าสู่คิวเพื่อให้เจ้าหน้าที่หรือช่างดำเนินการตามขั้นตอน

  3. 03

    ประสานวันและเวลา

    ผู้เกี่ยวข้องตรวจสอบความพร้อมและจัดการนัดหมายเมื่อจำเป็น

  4. 04

    ดำเนินการซ่อม

    ช่างอัปเดตความคืบหน้าและบันทึกข้อมูลที่เกี่ยวข้องกับการซ่อม

  5. 05

    ปิดงานและเก็บประวัติ

    ผลการดำเนินงานถูกสรุปและย้อนดูได้ตามสิทธิ์ของแต่ละบทบาท

Student Interface

ตัวอย่างหน้าจอจากคู่มือการใช้งานจริง

ชุดภาพนี้เป็นภาพหน้าจอฝั่งนักศึกษาที่ใช้อยู่ในคู่มือของระบบ เลือกมาเฉพาะส่วนที่ช่วยให้เห็นรูปแบบการใช้งานโดยรวม

ฝั่งช่างและผู้ดูแลระบบ

ในหน้า Showcase นี้จะแสดงขอบเขตโมดูลและหน้าที่หลักก่อน โดยไม่สร้างภาพจำลองขึ้นมาแทนหน้าจอจริง เมื่อมีภาพหน้าจอที่คัดและตรวจข้อมูลแล้ว สามารถเพิ่มเข้า Gallery ภายหลังได้โดยไม่ต้องเปิดระบบจริง
